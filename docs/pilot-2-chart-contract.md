# pilot-preservation-002 図の契約

- 問い: 同じ新規Runの再検証可能な総トークンと有効な57 ID充足率が揃ったか。効果や優劣の推定はしない。
- 粒度: 独立した実装Run。許可上限はnormal/anti各1。追加取得や57 IDの擬似反復で点数を増やさない。
- 成果物: 既存analysis/collect_runs.pyとanalysis/plot.pyによるCSV・静的PNG。Run ID、条件、管理バッチ、版、終了理由、欠測、有効性、分母と対応原本を保持する。
- 図: x=実測総トークン、y=有効な57 ID充足率。最大2点を条件とRun IDで識別する。少数点は個別観測の位置確認専用であり、回帰線や因果説明を加えない。旧Runと合成校正を混ぜない。
- 欠測: 品質null/使用量欠測は0として描かず、欠測CSVと表へ残す。未開始予定は実Runに変換せず、別の予定状態表で示す。
- 見た目: 白背景・青/橙と中立色、マーカー形状と直接ラベルでも条件を識別。品質軸0–100%。表を正確な値の確認先とする。
- QA: 保存PNGを実際に開き、点とCSV/原本の一致、軸・分母・ラベル・欠測の表示、切れや重なりを確認する。図と表も保全・復元する。
